# Documentação

Este repositório reúne implementações de uma calculadora simples em diferentes linguagens e modelos de interface.

## Categorias

- Terminal: execução via console
- Graphic: execução com interface visual

## Linguagens incluídas

- Go
- C++
- Rust

## Objetivo

Comparar a lógica da mesma funcionalidade em diferentes ecossistemas de desenvolvimento, mantendo a mesma estrutura de operação:

- escolha da operação
- leitura dos números
- cálculo
- exibição do resultado
- validação de divisão por zero
